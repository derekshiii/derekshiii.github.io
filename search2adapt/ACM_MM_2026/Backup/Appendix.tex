\section{Detailed Toolbox of Segmentation Operators}
\label{app:toolbox}

To enable effective pseudo-label generation and refinement in the source-free setting, 
we design a modular toolbox that provides the agents with diverse and controllable 
image processing operations. The toolbox consists of three categories: 
(1) Vision Foundation Model proposer tools, 
(2) image preprocessing tools, and 
(3) mask postprocessing and analysis tools.

\subsection{Vision Foundation Model (VFM) Proposer Tools}

These tools leverage large-scale pretrained VFMs to generate initial pseudo-labels 
or re-segment unreliable regions under severe domain shifts.

\subsubsection{BiomedParse}

\textbf{Implementation.}
Built upon a 371M-parameter model, BiomedParse operates on 3D volumes using 
slice-wise inference followed by spatial interpolation (default size = 512). 
A 2D variant is used for RGB medical images.

\textbf{Functionality.}
It performs text-guided semantic segmentation, mapping anatomical prompts 
to multi-label masks. It is primarily used when 
the source model fails to provide meaningful predictions.

\subsubsection{SAM3}

\textbf{Implementation.}
SAM3 is an 862M-parameter model supporting bounding box and text prompts, 
with multi-GPU inference for efficiency.

\textbf{Functionality.}
Unlike BiomedParse, SAM3 focuses on precise boundary delineation. It is typically 
applied to refine coarse masks or correct boundary leakage.

\subsubsection{DualExpert}

\textbf{Implementation.}
A two-stage pipeline combining BiomedParse and SAM3. Initial semantic masks 
are generated by BiomedParse, followed by bounding box extraction and refinement 
using SAM3. The final mask is obtained via union fusion.

\textbf{Functionality.}
This tool integrates semantic reasoning and geometric precision, and is used 
in scenarios with severe domain shift where single VFM predictions are unreliable.

\subsection{Image Preprocessing Tools}

These tools mitigate domain discrepancies before segmentation.

\subsubsection{NormalizeIntensity}

\textbf{Implementation.}
Based on MONAI's \texttt{ScaleIntensityRange}, intensities are clipped to 
a predefined range (e.g., HU values in CT) and rescaled.

\textbf{Functionality.}
Used for standardizing intensity distributions across domains.

\subsubsection{ClipIntensity}

\textbf{Implementation.}
Applies percentile-based clipping (default 1\%--99\%) followed by rescaling.

\textbf{Functionality.}
Handles long-tailed distributions and improves effective contrast.

\subsubsection{EnhanceImage}

\textbf{Implementation.}
Supports gamma correction and histogram normalization.

\textbf{Functionality.}
Enhances contrast under skewed intensity distributions or multi-modal histograms.

\subsubsection{SmoothImage}

\textbf{Implementation.}
Includes Gaussian and median filtering with configurable parameters.

\textbf{Functionality.}
Reduces noise while preserving anatomical structures, depending on noise type.

\subsection{Mask Postprocessing and Analysis Tools}

These tools refine pseudo-labels using geometric and anatomical priors.

\subsubsection{PostprocessSegmentation}

\textbf{Implementation.}
A pipeline including small component removal, largest component selection, 
and hole filling.

\textbf{Functionality.}
Provides basic mask cleanup and is typically applied after initial segmentation.

\subsubsection{IterativeHoleFill}

\textbf{Implementation.}
Performs iterative hole filling with varying connectivity.

\textbf{Functionality.}
Targets large and complex internal cavities in organs.

\subsubsection{ConditionalFill}

\textbf{Implementation.}
Applies hole filling conditioned on minimum volume priors.

\textbf{Functionality.}
Prevents overfilling by selectively repairing under-segmented organs.

\subsubsection{Morphological Operations}

\textbf{Implementation.}
Includes closing, opening, and multi-label variants with adaptive kernel sizes.

\textbf{Functionality.}
Used to repair discontinuities or remove boundary artifacts.

\subsubsection{BoundaryRefinement}

\textbf{Implementation.}
Combines erosion and dilation to sharpen boundaries.

\textbf{Functionality.}
Improves edge precision under partial volume effects.

\subsubsection{GaussianSmoothMask}

\textbf{Implementation.}
Applies Gaussian smoothing on probability maps followed by re-thresholding.

\textbf{Functionality.}
Reduces staircase artifacts from patch-based inference.

\subsubsection{RemoveOutlierLabels}

\textbf{Implementation.}
Removes components based on centroid distance to the main region.

\textbf{Functionality.}
Eliminates anatomically implausible false positives.

\subsubsection{LabelFilter}

\textbf{Implementation.}
Removes specified labels from the mask.

\textbf{Functionality.}
Allows selective re-segmentation of failed classes.

\subsubsection{SymmetryChecker}

\textbf{Implementation.}
Analyzes volume ratios and mirrored overlap for paired organs.

\textbf{Functionality.}
Provides diagnostic feedback for detecting asymmetry or structural errors.
