Search2Adapt: Multi-Agent Collaborative Tree Search for Source-Free Unsupervised Domain Adaptation

Yulong Shi, Wenwen Zhang, Ziyi Li, Lin Qi*
Northeastern University, Shenyang, China
Paper Code

Abstract

Source-Free Unsupervised Domain Adaptation (SFUDA) aims to adapt a pre-trained source model to unlabeled target domains without accessing source data. Traditional SFUDA methods rely on static pseudo-label generation, which often leads to suboptimal adaptation due to error accumulation and lack of feedback mechanisms. We present Search2Adapt, a novel multi-agent collaborative framework that reformulates SFUDA as a dynamic strategy search problem. Our approach introduces Collaborative Tree Search (CoTS), a plan-level search algorithm that enables efficient exploration of pseudo-label refinement strategies through multi-agent collaboration. The framework employs a closed-loop decision process where a Perceptor analyzes domain characteristics, a Strategist proposes adaptation plans, and an Evaluator provides multi-dimensional feedback without ground-truth labels. A Dynamic Prior Memory accumulates successful strategies across samples for accelerated adaptation. Extensive experiments on medical image segmentation benchmarks demonstrate that Search2Adapt achieves state-of-the-art performance, surpassing existing methods by significant margins while maintaining computational efficiency.

Method

Closed-Loop Multi-Agent Framework

Transforms traditional open-loop SFUDA pipelines into feedback-driven decision processes through collaboration between Perceptor, Strategist, and Evaluator.

Plan-Level Tree Search (CoTS)

Operates on complete tool-chain plans rather than individual actions, significantly reducing computational overhead while exploring diverse adaptation strategies.

Anatomy-Aware Reward

Multi-dimensional scoring mechanism that evaluates pseudo-label quality without ground-truth labels, considering anatomical plausibility, morphological consistency, and boundary precision.

Overview of Search2Adapt. The framework employs a closed-loop multi-agent collaboration where Perceptor analyzes domain characteristics, Strategist proposes adaptation plans, and Evaluator provides feedback. CoTS explores the strategy space through tree search, guided by an anatomy-aware reward mechanism.

Collaborative Tree Search (CoTS). The two-phase search process: Phase 1 uses LLM-based plan evaluation without execution, and Phase 2 verifies top-K plans through actual execution. The diversity-augmented CAVF formula balances exploitation, exploration, and strategy diversity.

Key Features

Diversity-Augmented CAVF

Our Collaborative Action Value Function (CAVF) extends UCT with a diversity bonus to prevent premature convergence:

CAVF(si) = V(si) + w·√(ln Nparent/Ni) + λ/√(count(toolsigi))

Exploitation Exploration Diversity Bonus

Dynamic Prior Memory

Five-layer memory structure enables cross-sample knowledge transfer:

  • Domain Profile — Perceptor's analysis of target domain characteristics
  • Adaptation Plans — Strategist's candidate plans with success history
  • Trajectories — Successful tool chains for similar domains
  • Plan Dialogues — CoTS collaboration records for learning
  • Evaluation Records — Historical scoring for strategy refinement
