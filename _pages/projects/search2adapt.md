<h1>Search2Adapt: Multi-Agent Collaborative Tree Search for Source-Free Unsupervised Domain Adaptation</h1>

<p>
<strong>Yulong Shi</strong>, Wenwen Zhang, Ziyi Li, Lin Qi.<br />
<em>The 34th ACM International Conference on Multimedia</em> (ACM MM), 2026. <span style="color:red;"><b>CCF-A, CORE A*</b></span>
</p>

<h2>Abstract</h2>
<p>
  Search2Adapt proposes a multi-agent collaborative tree search framework for source-free unsupervised domain adaptation (SFUDA). The method leverages vision foundation models to autonomously explore and adapt to target domains without accessing source data, using cooperative search agents to discover optimal adaptation strategies.
</p>

<h2>Method Overview</h2>
<p>
  The framework employs multiple agents that collaboratively search through a tree-structured adaptation space. Each agent explores different adaptation paths while sharing knowledge, enabling efficient discovery of optimal domain alignment strategies without requiring source data access.
</p>
